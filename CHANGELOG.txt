0.1.32 (2026-10-12)
- Program renamed to MonoLith everywhere: MonoLith.exe, MonoLith folder, window/menus/dialogs.
- New file extensions: .lithprt (part), .lithasm (assembly), .lithpln (plan).
- Old .ekprt/.ekasm/.ekpln files still open; the first Save asks to store them as the new extension (the old file is kept).
- Updater is now UPDATE-MONOLITH.bat with MonoLith-patch.zip; it renames the old EKCAD folder and exe to MonoLith once.
- Recent files and action-log setting are carried over. Dark mode and UI scale need to be set once more.

0.1.31 (2026-10-11)
- New "Interface" menu (next to View): Dark Mode on/off, UI Scale… (slider 60%–200%, remembered) and Reset UI Scale.
- The dark mode button in the top bar has moved to Interface > Dark Mode.

0.1.30 (2026-10-11)
- Dark mode: sketches on an empty plane now use light colours (white = fully defined, light blue = under defined, light dimension lines); sketches on a part face keep black/blue. Dimension numbers are always dark on their white label.

0.1.29 (2026-10-11)
- Sketch colours in dark mode now match light mode: black = fully defined, blue = under defined (dimension text readable again).
- Selected sketch geometry is now magenta instead of light blue, so it can't be confused with under-defined (blue).

0.1.28 (2026-10-11)
- Internal: program code reorganised into smaller files per topic (faster, safer updates). No change in how the program works.

0.1.27 (2026-10-11)
- Action log permission popup now explains exactly what is and isn't recorded, where the log is stored, that it is never sent anywhere, and how long it is kept. Shown once more so you can review your choice.

0.1.26 (2026-10-11)
- New: action log. Monolith records what you do (commands, clicks, keys, field values) and any errors in the "Logs" folder next to the program (one file per day, kept 14 days). Asks for permission on first start; can be switched on/off on the Home screen (on by default).

0.1.25 (2026-10-11)
- Viewport: Shift + middle-mouse drag now pans, Ctrl + middle-mouse drag now zooms (swapped).

MONOLITH (EKCAD) - CHANGELOG
============================
Newest version at the top. Install a patch by double-clicking UPDATE-EKCAD.bat.

0.1.24  (11 Oct 2026)
  - Part: double-click a face to show the feature that made it:
    its sketch is shown on top of the model with its dimensions, and the feature
    parameters (Depth, Angle, Radius, ...) appear as orange labels.
  - Double-click one of those dimensions to change it; the part rebuilds (undo works).
  - Click empty space or press Esc to hide the dimensions again.
  - FeatureManager tree: hovering over a feature highlights its faces in the viewport
    (orange) and shows its sketch.

0.1.23  (11 Oct 2026)
  - Assembly: Measure tool (Evaluate tab). Edge length / diameter, face area,
    centre distance, normal distance or angle - also between different components.

0.1.22  (11 Oct 2026)
  - Assembly: Width mate. In Mate, select 2 parallel faces on one
    component and 2 on another -> the second component is centred between the first.

0.1.21  (11 Oct 2026)
  - Section View: dotted X and Y lines are always shown across the cut plane.

0.1.20
  - Section View: drag the red cut face or scroll the mouse wheel over it to move the cut.
  - "Saved Views" folder in the tree with "Cross section N" entries (on/off, edit,
    flip side, rename, delete). Clicking Section View while a section is on turns it off.

0.1.18 - 0.1.19
